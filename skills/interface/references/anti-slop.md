anti-slop

generated interfaces converge on same defaults
each item fine when brief asks for it | problem when nobody decided otherwise

visual tells
- purple/indigo-to-blue gradients | aurora/mesh blobs | glowing orbs behind hero
- gradient text on headings | neon outer glows | glassmorphism on every card
- centered hero over dark gradient + pill badge ("New: v2.0 is here") above headline
- same three cards (icon in rounded square, bold title, two lines gray text) as main feature section
- big-number "hero metrics" row (10k+ users, 99.9% uptime, 24/7 support) with no source
- cards inside cards | everything in soft-shadowed rounded rectangle
- thick colored left border on callouts, alerts, list items
- hard offset "neo-brutalist" shadows (4px 4px 0 black) on otherwise soft design
- sparklines, progress rings, fake charts as decoration instead of real data
- monospace everywhere to look "technical" with no code or data
- emoji or Unicode glyphs as icons | mixed icon families | generic user-silhouette avatars
- fake product screenshots from divs (fake terminals, task lists, dashboards)
- unthemed leftovers beside custom design: blue selection | default focus ring | native controls in wrong `color-scheme` or `accent-color` | native scrollbars + date inputs stay native, only themed
- three "designed" looks used as reflexes
  1. warm cream background + high-contrast serif + terracotta/brass accent
  2. near-black + one acid neon accent + glowing borders
  3. newspaper hairlines + italic display serif + tiny tracked mono labels
- Inter or system sans as brand landing display face | overused "designer" faces picked by habit: Fraunces, Playfair Display, Instrument Serif, Space Grotesk, Syne
- light/dark chosen by category ("dev tool = dark") instead of user's scene

layout tells
- eyebrow label above every heading ("FEATURES", "HOW IT WORKS") | at most one eyebrow per three sections
- section numbers "01 / 02 / 03" when content is not a real sequence
- "big headline left, small paragraph right" as every section header
- six identical image-left/text-right rows in a row
- bento grids with empty cells or six plain white text cells
- logo wall with industry labels under each logo | plain-text "logos"
- trust strip, pricing teaser, bullet list crammed into hero
- hero overflowing first viewport | 4-line headline
- "scroll to explore" cues | rotated vertical text | decorative crosshairs + grid lines as filler
- two marquees on one page | marquee as filler

copy tells
- filler verbs: Elevate, Seamless, Unleash, Empower, Supercharge, Revolutionize, Next-gen, Game-changer, Delve, Unlock the power of
- generic names: John Doe, Jane Smith, Acme Corp, Nexus, Cloudly, SmartFlow
- fake-precise metrics (99.97%, 4.1x faster, 2,847 teams) without real source
- lorem ipsum | "Your text here" | headings describing the section ("Our Features")
- three adjectives in a row ("fast, secure and reliable") | headlines fitting any product
- mixed registers (marketing hype + technical jargon + poetry)
- em dashes everywhere | over-used middle dots as separators
- "Get started", "Learn more", "Sign up", "Try it free" all on one page for same action

motion tells
- every section fades up identically on scroll
- infinite pulses, breathing glows, floating blobs with no meaning
- bouncy springs on menus + modals
- custom cursors + magnetic buttons on normal product site

instead
- palette, type, one signature element from subject's own world (`direction.md`)
- structure from content | 2 features show 2 | hero feature goes big
- real assets: screenshots, photos, product UI, custom illustration in one style | missing asset: ask or leave marked placeholder, never cover with gradients
- copy only this product could say: specific nouns, real numbers, concrete outcomes
- one focal motion moment + purposeful micro-interactions, nothing else
- specificity test: competitor could use page unchanged with their logo = not done
